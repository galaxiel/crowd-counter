# CHANGEMENT DE CONTRAT v3 : plus de torch, plus d'ultralytics, plus de
# téléchargement de 2,4 Go au premier lancement. L'inférence passe par
# ONNX Runtime ; le prétraitement et le NMS (ex-travail d'ultralytics)

# ONNX Runtime, en deux habillages selon l'OS (même module `onnxruntime`) :
# - Windows : `onnxruntime-directml` — la couche GPU de Windows (DirectML)
#   pilote NVIDIA, AMD ET Intel ; mesuré sur RTX 4070 : 51 i/s (88 % de
#   torch, voir docs/design/v3-onnx-proposition.md) ;
# - ailleurs (CI Linux) : `onnxruntime` CPU — la suite ne fait aucune
#   inférence, seul l'import compte.

onnxruntime>=1.20; sys_platform != 'win32'
