# Journal d'avancement — crowd-counter

Le journal daté du travail livré : ce qui est vérifié (et comment), ce qui a été trouvé cassé, ce qui reste à faire — une entrée par séance ou par lot/PR.  
Règle : tout lot ou PR qui change le comportement du produit met ce journal à jour ; une affirmation sans preuve s'écrit « non vérifié ».
